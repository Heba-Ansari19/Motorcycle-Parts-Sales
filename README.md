# Motorcycle-Parts-Sales

This project analyzes wholesale sales data for a motorcycle parts company, calculating net revenue by product line across different warehouses and months. Using SQL, it examines sales patterns, identifies top-performing products, and provides actionable insights to optimize revenue and understand customer trends.
<br>
<br>

## Project Overview

This project analyzes sales data for a company that sells motorcycle parts across three warehouses: North, Central, and West. The company serves both retail and wholesale clients and accepts multiple payment methods, each with a specific fee. 

The main goal is to understand **wholesale net revenue** by product line, month, and warehouse. Analyzing this data helps identify top-performing product lines, seasonal trends, and regional differences, enabling data-driven decisions for inventory management, sales planning, and profitability optimization.
<br>
<br>

## Objective / Key Questions
* Calculate net revenue for each product line by month and warehouse for wholesale orders.  
<br>

### 3. Wholesale Net Revenue by Product Line, Month, and Warehouse

```
sql

SELECT 
	product_line,
	CASE WHEN EXTRACT(month FROM date) = 6 THEN 'June' 
		WHEN EXTRACT(month FROM date) = 7 THEN 'July'
		WHEN EXTRACT(month FROM date) = 8 THEN 'August' 
	END AS month,
	warehouse,
	SUM(total) - SUM(payment_fee) AS net_revenue
FROM sales
WHERE client_type = 'Wholesale'
GROUP BY 
	product_line,
	warehouse,
	client_type = 'Wholesale',
	EXTRACT(month FROM date)
ORDER BY 
	product_line,
	EXTRACT(month FROM date),
	net_revenue DESC;
```
This query calculates the net revenue generated by wholesale orders for each product line, grouped by warehouse and month. The CASE statement converts numeric months into human-readable names (June, July, August). SUM(total) - SUM(payment_fee) computes the net revenue by subtracting fees associated with payment methods from total sales. The WHERE client_type = 'Wholesale' filter ensures that only wholesale orders are analyzed. Grouping by product_line, warehouse, and month allows comparison across product categories, locations, and time periods. The query helps identify high-revenue product lines, seasonal trends, and warehouse-specific performance patterns.

## INSIGHTS AND FINDINGS
